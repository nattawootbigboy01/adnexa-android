# ADNEXA Android

Flutter Android app for Meta advertising insights and campaign planning. The current working branch is `feature/meta-oauth-backend-20261110`; do not merge to `main` or deploy the Worker without separate approval.

## Current branch scope

- **Dashboard and Insights:** account-level Meta Ads reporting through the ADNEXA Cloudflare Worker. Read-only; requires a connected Meta test/business account and approved `ads_read` permission.
- **Account Center:** official Meta OAuth connection. The Worker stores the access token encrypted at rest; the app does not receive the token.
- **Campaign Studio:** local planning and draft storage only. No campaign create, edit, pause, publish, or spend endpoint is implemented.
- **AI Planner:** offline rule-based planning helper. It is not connected to a hosted AI model.
- **Admin Control Center:** read-only system overview, Meta connection metadata, and admin audit events. It is visible only to Firebase users with the trusted custom claim `admin: true` or `role: "admin"`; the Worker independently verifies the same claim. There is no self-service admin promotion or role-management UI.

## Safety and release status

- The Meta Insights endpoint is GET-only and read-only.
- No live campaign operation or ad-spend action is implemented.
- Worker changes on this branch have **not** been deployed. Production may still be on the previously deployed Worker version.
- Live Insights verification with an app-role/test user and `ads_read` is pending a separately approved test deployment.
- The proposed in-app brand currently reads **ADNEXA ADS**; final brand-name approval is pending.
- The Android launcher icon and app label are generated by the APK workflow. No APK build has yet been verified for this branch.

Never place Firebase credentials, Meta app secrets, encryption keys, access tokens, or passwords in source code, screenshots, or chat. Configure Firebase build values only as GitHub Actions repository variables and keep Worker secrets in Cloudflare.

## Build and test on the feature branch

1. Open the repository's **Actions** tab.
2. Select **Build ADNEXA APK**.
3. Choose branch `feature/meta-oauth-backend-20261110` in **Run workflow**.
4. Wait for dependency installation, `flutter analyze`, `flutter test`, and the release APK build to complete.
5. Download the `adnexa-android-apk` artifact from a successful run.

The workflow also runs on pushes to this feature branch. It does not deploy the Cloudflare Worker or publish an app.

GitHub Actions usage is subject to the account's included minutes and storage quota. No paid service or payment method is configured by this project.

## Local build

Install Flutter, then run:

```sh
flutter pub get
flutter analyze
flutter test
flutter create . --platforms=android --project-name adnexa
flutter build apk --release
```
