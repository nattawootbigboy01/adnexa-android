# ADNEXA — ร่างประกาศความเป็นส่วนตัวและข้อความขอความยินยอม (ฉบับร่าง)

> **ห้ามนำขึ้นใช้งานจริงก่อนกรอกข้อมูลผู้ควบคุมข้อมูล ช่องทางติดต่อ ผู้ประมวลผลข้อมูล ระยะเวลาเก็บรักษา และให้ผู้เชี่ยวชาญกฎหมายไทยตรวจทาน** เอกสารนี้เป็นร่างผลิตภัณฑ์ ไม่ใช่คำปรึกษากฎหมาย และไม่รับประกันว่าจะป้องกันการถูกฟ้องร้องได้

## 1. ข้อความที่แสดงก่อนสมัคร

**ประกาศความเป็นส่วนตัวของ ADNEXA**

ADNEXA [ชื่อบุคคล/นิติบุคคลผู้ให้บริการ] เป็นผู้ควบคุมข้อมูลส่วนบุคคลของคุณ ติดต่อได้ที่ [อีเมล/ที่อยู่/ช่องทางติดต่อ]

เราเก็บและใช้ข้อมูลเท่าที่จำเป็นเพื่อ:
- สร้างและดูแลบัญชี ยืนยันตัวตน และรักษาความปลอดภัย
- ให้บริการจัดการโฆษณา เชื่อมต่อบัญชีแพลตฟอร์มเมื่อคุณสั่งการ และแสดงผลรายงาน
- ให้บริการลูกค้า ตรวจสอบข้อร้องเรียน ป้องกันการทุจริต และปฏิบัติตามกฎหมาย
- ดำเนินการชำระเงิน/บัญชี หากคุณเลือกใช้บริการดังกล่าว

ข้อมูลที่อาจใช้ ได้แก่ อีเมล ชื่อหรือชื่อที่แสดง ข้อมูลบัญชีและการตั้งค่า ประวัติคำสั่ง/กิจกรรม ข้อมูลการชำระเงินที่จำเป็น และข้อมูลจากแพลตฟอร์มโฆษณาที่คุณอนุญาตให้เชื่อมต่อ เราจะไม่ขอรหัสผ่านบัญชี Meta, Google หรือ TikTok ของคุณ

เราอาจใช้ผู้ให้บริการที่จำเป็น เช่น โฮสติ้ง ฐานข้อมูล ระบบยืนยันอีเมล และผู้ให้บริการชำระเงิน โดยกำหนดหน้าที่รักษาความปลอดภัยและใช้ข้อมูลตามคำสั่ง/วัตถุประสงค์ที่เกี่ยวข้อง หากเชื่อมต่อแพลตฟอร์มโฆษณา จะมีการแจ้งข้อมูลและสิทธิ์ที่ขอเป็นรายแพลตฟอร์มก่อนเชื่อมต่อ ไม่ถือว่าการสมัครสมาชิกเป็นการอนุญาตให้แชร์ข้อมูลทุกชนิดโดยอัตโนมัติ

ระยะเวลาเก็บรักษา: [ระบุระยะเวลาแยกตามประเภทข้อมูลและเหตุผล] เมื่อหมดความจำเป็นจะลบ ทำลาย หรือทำให้ไม่สามารถระบุตัวบุคคลได้ เว้นแต่ต้องเก็บต่อเพื่อปฏิบัติตามกฎหมายหรือใช้สิทธิเรียกร้องตามกฎหมาย

คุณมีสิทธิตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล เช่น ขอเข้าถึง แก้ไข ลบ คัดค้าน จำกัดการใช้ ขอรับ/โอนย้ายข้อมูล และถอนความยินยอมในกรณีที่อาศัยความยินยอม โดยการถอนความยินยอมไม่กระทบการประมวลผลที่ทำไปก่อนถอน ติดต่อได้ที่ [ช่องทางใช้สิทธิ/เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล ถ้ามี]

กรณีมีการส่งหรือโอนข้อมูลไปต่างประเทศ เราจะแจ้งประเทศ/ผู้รับ/มาตรการคุ้มครองและฐานกฎหมายที่ใช้ตามกรณีก่อนดำเนินการ

## 2. ช่องเลือกในหน้าสมัครสมาชิก

**ช่องที่จำเป็นสำหรับการสมัคร**
- [ ] ข้าพเจ้าได้อ่านประกาศความเป็นส่วนตัวของ ADNEXA และรับทราบรายละเอียดเกี่ยวกับการเก็บ ใช้ เปิดเผย ระยะเวลาเก็บรักษา และสิทธิของเจ้าของข้อมูลแล้ว

> ช่องนี้เป็นการรับทราบประกาศ ไม่ควรเขียนให้เป็น “ยินยอมทุกอย่าง” และไม่ควรใช้แทนฐานกฎหมายของการประมวลผลที่จำเป็นต่อสัญญาหรือหน้าที่ตามกฎหมาย

**ความยินยอมเพิ่มเติม — ไม่บังคับและไม่ผูกกับการสมัคร**
- [ ] (ตัวเลือก) ข้าพเจ้ายินยอมให้ ADNEXA ใช้อีเมล/ช่องทางติดต่อเพื่อส่งข่าวสาร โปรโมชั่น และข้อเสนอทางการตลาด ข้าพเจ้าสามารถถอนความยินยอมได้ทุกเมื่อผ่าน [วิธีถอน/ลิงก์/ตั้งค่า]

ผู้ใช้ต้องสมัครได้แม้ไม่เลือกช่องการตลาด และช่องการตลาดต้องไม่ถูกเลือกไว้ล่วงหน้า

## 3. การส่งข้อมูลให้แพลตฟอร์มโฆษณา

ก่อนเชื่อมต่อ Meta Ads, Google Ads หรือ TikTok Ads ให้แสดงหน้าต่างแยกที่ระบุ:
- แพลตฟอร์มและผู้รับข้อมูลที่แน่นอน
- ประเภทข้อมูล/สิทธิ์ OAuth ที่ร้องขอ
- วัตถุประสงค์และฟังก์ชันที่จะทำงาน
- การเพิกถอนสิทธิ์จาก ADNEXA และจากแพลตฟอร์ม
- การโอนข้อมูลข้ามประเทศ (ถ้ามี) และมาตรการที่ใช้

ขอเฉพาะ scope ที่จำเป็น ห้ามส่งข้อมูลลูกค้าไปแพลตฟอร์มเพื่อวัตถุประสงค์อื่นโดยไม่มีฐานกฎหมายและการแจ้งที่เหมาะสม

## 4. หลักฐานความยินยอมและการรับทราบ

เมื่อผู้ใช้กดเลือก/ยืนยัน ให้บันทึกอย่างปลอดภัย:
- รหัสผู้ใช้ภายใน
- ประเภทการเลือก: privacy_notice_acknowledged หรือ marketing_consent
- ค่า true/false และเวลาที่บันทึก (UTC)
- เวอร์ชันเอกสาร/ข้อความที่แสดง
- ช่องทางและเวอร์ชันแอป
- เวลาถอนความยินยอมและสถานะล่าสุด (ถ้ามี)

ห้ามบันทึกรหัสผ่านหรือ token ลับลงบันทึก consent และจำกัดสิทธิ์เข้าถึงหลักฐานนี้ การเปลี่ยนข้อความต้องเพิ่ม version ใหม่ ไม่เขียนทับประวัติเดิม
